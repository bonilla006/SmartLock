# Proposito
SmartLock es una aplicación web desarrollada con Flask que permite gestionar cerraduras inteligentes mediante comunicación MQTT. La aplicación proporciona una interfaz para que los usuarios puedan controlar remotamente sus dispositivos IoT de seguridad, monitorear accesos y gestionar múltiples cerraduras.
- El mismo cuenta con dos componentes:
    - La aplicacion Flask
    - el dispositivo iot
